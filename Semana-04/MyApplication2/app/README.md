# Lab 04: Manejo de Estado en Jetpack Compose

Proyecto de Laboratorio 04 para el curso de Programación en Móviles (Tecsup).

## Componentes del Proyecto

* **TemperatureDisplay.kt**: Control de temperatura usando `remember` y `mutableStateOf` con actualización de colores según el valor.
* **TaskScreen.kt**: Lista de tareas reactiva con `LazyColumn` (agregar, marcar y eliminar).
* **MainActivity.kt**: Integración principal y vistas previas.
